# Banco de dados (Supabase)

Arquivos `.sql` para rodar no **SQL Editor** do Supabase.

- `schema.sql` — tabelas base do app.
- `add_savings_pots.sql` — reservas manuais.
- `add_monthly_plans.sql` — renda prevista por mês (aba Planejamento).
- `add_bill_payments.sql` — faturas de cartão pagas (botão "Pagar fatura").
